1. HTML

HTML (Hyper Text Markup Language) adalah bahasa standar untuk membuat struktur halaman web. HTML bukan bahasa pemrograman, melainkan bahasa markup yang mendefinisikan konten dan struktur.

HTML memiliki peran penting di dunia teknologi sebagai fondasi utama dan struktur dasar untuk menampilkan informasi secara visual di internet. Tanpa HTML, browser tidak akan bisa memahami bagaimana cara menyusun teks, gambar, atau video menjadi sebuah halaman yang rapi.

Berikut adalah fungsi-fungsi penting HTML di berbagai sektor teknologi saat ini:

  1. Penyusun Struktur Informasi Halaman Web
  2. Penghubung Antardokumen (Hyperlink)
  3. Media Integrasi Komponen Lain
  4. Optimasi Mesin Pencari (SEO)
  5. Aksesibilitas Digital (Accessibility)
  6. Pengembangan Aplikasi Lintas Platform (Cross-Platform)

Untuk mehamaminya lebih gampang saya analogikan sebagai rumah. Pada bentuk rumah, HTML berperan sebagai Kerangka rumah atau Pondasi. dalam Mata Kuliah Desain Web Dinamis, rumah adalah Web.

Tag pada HTML adalah kode atau penanda khusus yang digunakan untuk menginstruksikan peramban (browser) bagaimana cara menyusun dan menampilkan sebuah konten.
Tag berfungsi sebagai instruksi tersembunyi. Browser tidak akan memunculkan tulisan tag tersebut secara langsung, melainkan mengubahnya menjadi tampilan visual (seperti teks tebal, gambar, atau tombol) sesuai dengan fungsi dari masing-masing tag.

Berikut berbagai Macam tag pada HTML beserta penjelasannya :

  1. <!DOCTYPE html> : Deklarasi untuk memberi tahu browser bahwa dokumen ini menggunakan standar versi HTML5.
  2. <html> : Tag utama (root) yang membungkus seluruh elemen kode HTML pada halaman.
  3. <head> : Tempat menyimpan informasi latar belakang/metadata web (seperti judul browser, link CSS, set karakter) yang tidak muncul langsung di area konten web.
  4. <title> : Menentukan judul halaman yang muncul pada tab di paling atas browser.
  5. <body> : Wadah utama tempat semua isi web (teks, gambar, tombol, list) berada dan terlihat oleh pengguna.
  6. <h1> sampai <h6> : Menentukan tingkatan judul/heading (h1 terbesar, h6 terkecil).
  7. <p> : Digunakan untuk membuat paragraf teks.
  8. <br> : Memberikan ganti baris (enter) tanpa membuat paragraf baru.
  9. <ol> : (Ordered List) Membuat daftar berurutan bernomor (1, 2, 3, dst.) yang posisinya otomatis menjorok ke dalam.
  10. <ul> : (Unordered List) Membuat daftar tidak berurutan dengan simbol poin (bullet points).
  11. <li> : (List Item) Menandai tiap-tiap butir/item di dalam tag ol atau ul.
  12. <a> : Membuat tautan/link menuju halaman lain.
  13. <img> : Menampilkan gambar pada halaman web.

Sebetulnya masih banyak lagi Tag pada HTML yang tertera hanya yang umum saja, Untuk memahami setiap Tag yang ada, kamu bisa langsung praktik dan mengimplementasikannya.
